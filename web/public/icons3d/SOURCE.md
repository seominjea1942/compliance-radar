# 3D tab icons

Three renders from the **3dicons.co v1 collection** by realvjy, released
**CC0** (public domain, no attribution required; noted here anyway).

| file | icon in the collection | used for |
| --- | --- | --- |
| `overview.webp` | Target | Overview |
| `log.webp` | Notebook | Log |
| `profile.webp` | Bag | Store profile |

Fetched at 200×200, `dynamic` style, `color` finish:
`https://3dicons.co/collection/b68cf8-v1`

**These files have no alpha channel.** Their background is opaque white, so
they only sit flush on a white surface. The application bar is `--color-paper`,
which is white, so it works there; anything else behind a tab, a hover fill
included, would show as a white square around the icon.
